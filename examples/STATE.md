# 项目交接状态

- 更新时间：
- 项目目标与本次授权范围：
- 仓库、分支、commit：
- 当前实例标识、工作目录（私有记录中填写）：
- Agent / 模型来源 / 版本（无密钥）：
- 已验证完成：
- 正在运行的任务 ID、启动时间、命令、tmux session：
- 日志 / checkpoint / 产物路径：
- 实例外备份位置、最后同步时间与校验记录：
- 失败或未验证的事项：
- 下一步最小动作：
- 停止条件与预算：

恢复规则：先核验进程、日志和产物，再决定是否重启任务；不得仅因聊天上下文丢失而重复提交训练。进程退出不等于实验成功，完成必须满足项目自己的验收。
